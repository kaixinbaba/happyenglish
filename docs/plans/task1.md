# 错题统计页面 - 任务拆分文档

## 概述
创建一个完整的错题统计页面，包含错题分布统计和复习历史统计。

---

## Module 1: 后端统计 API 扩展

### Task 1.1: 扩展复习统计 API
**文件**: `src/app/api/error-questions/review/statistics/route.ts`

**实现要点**:
- 添加复习历史相关的统计数据
  - 总复习次数统计
  - 每日复习次数趋势（近30天）
  - 累计正确/错误率统计
  - 平均掌握度提升趋势
- 添加错题掌握度分布统计
  - 按掌握度区间分组统计（0-20, 20-40, 40-60, 60-80, 80-100）
- 添加复习会话统计
  - 平均每次复习题数
  - 平均正确率变化趋势
- 保持现有统计功能不变

**验收标准**:
- [ ] API 返回包含所有新增统计数据
- [ ] 数据格式清晰，易于前端使用
- [ ] 性能良好，查询时间 < 500ms
- [ ] 有错误处理和日志记录

### Task 1.2: 复习统计详情 API
**文件**: `src/app/api/error-questions/review/statistics/route.ts` (或新建)

**实现要点**:
- 可选：创建一个支持时间范围筛选的统计接口
- 支持按周/月/自定义时间范围查询
- 返回更详细的趋势数据

**验收标准**:
- [ ] API 支持时间范围参数
- [ ] 返回正确的时间范围数据
