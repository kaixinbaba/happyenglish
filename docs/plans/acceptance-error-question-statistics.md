# 错题统计页面 — 人工验收手册

生成时间：2026-05-06

## 执行规则

1. 按步骤顺序执行
2. 每步完成后立即标记状态
3. 阻塞标记 `[~]` 并记录原因

## 验收前准备

- 使用已登录账号访问应用
- 账号下建议至少包含若干错题、标签和复习记录，便于观察图表数据
- 重点验收页面：`/error-questions`、`/error-questions/statistics`、`/error-questions/review/history`
