# happyenglish 错题集功能 — 任务拆分
> 目标：实现错题集核心功能，支持手动录入错题、自动关联知识点、错题统计分析、个性化复习推荐，适配小学生英语学习场景
> 约束：复用现有happyenglish技术栈（Next.js + Drizzle ORM + PostgreSQL + 飞书登录），不引入新的第三方依赖
> 关联文档：需求讨论记录 - 支持7种题型，降低录入成本，关联单词掌握度

## Module 2：后端接口开发
> 前置条件：Module 1 所有任务完成
### Task 2.1 — 错题CRUD接口开发
**目标**：实现错题的增删改查接口
**执行优先级**：
1. 实现错题列表查询接口（支持按题型、知识点、掌握度筛选）
2. 实现错题新增/编辑/删除接口
3. 实现错题批量导入导出接口（后续扩展，本期先做手动录入）
**验收标准**：
- [ ] 接口支持7种题型的完整字段存储
- [ ] 接口参数校验完整，错误提示明确
- [ ] 接口权限控制正确，用户只能访问自己的错题
**关联文件**：`src/app/api/error-questions/`
### Task 2.2 — 知识点与单词关联接口
**目标**：实现错题自动关联知识点和单词的能力
**执行优先级**：
1. 实现错题录入时自动提取核心单词，关联到用户单词表
2. 实现错题知识点自动打标接口
3. 实现错题关联单词的掌握度自动更新接口（错误次数+1，掌握度下降）
**验收标准**：
- [ ] 录入错题时自动提取单词并关联成功
- [ ] 单词错误次数、掌握度更新正确
- [ ] 知识点打标准确率≥90%
### Task 2.3 — 个性化复习推荐接口
**目标**：基于艾宾浩斯遗忘曲线和用户掌握度，生成复习计划
**执行优先级**：
1. 实现复习任务生成接口，按掌握度和遗忘时间排序
2. 实现复习完成后更新掌握度接口
3. 实现错题统计接口（总错题数、掌握率、高频错点）
**验收标准**：
- [ ] 复习推荐顺序符合遗忘曲线规则，薄弱知识点优先
- [ ] 复习完成后掌握度更新正确
- [ ] 统计数据准确，和实际错题数据一致
