## 附录：常用测试命令
### 接口测试示例（替换`你的用户ID`为实际登录用户的cookie值）
```bash
# 1. 测试错题新增接口
curl -X POST http://localhost:3000/api/error-questions \
  -b "user_id=你的用户ID" \
  -H "Content-Type: application/json" \
  -d '{
    "type": "spelling",
    "content": {"word": "beautiful", "hint": "美丽的"},
    "correctAnswer": "beautiful",
    "userAnswer": "beautifull",
    "errorReason": "多写了一个l",
    "tags": ["单词拼写", "初中词汇"],
    "relatedWords": ["beautiful"]
  }'

# 2. 测试错题列表接口（带筛选参数）
curl -X GET "http://localhost:3000/api/error-questions?type=spelling&masteryLevel=0&page=1&pageSize=10" \
  -b "user_id=你的用户ID"

# 3. 测试复习列表接口
curl -X GET http://localhost:3000/api/error-questions/review/list \
  -b "user_id=你的用户ID"

# 4. 测试复习统计接口
curl -X GET http://localhost:3000/api/error-questions/review/statistics \
  -b "user_id=你的用户ID"

# 5. 测试错题更新接口（替换QUESTION_ID为实际错题ID）
curl -X PUT http://localhost:3000/api/error-questions/QUESTION_ID \
  -b "user_id=你的用户ID" \
  -H "Content-Type: application/json" \
  -d '{"correctAnswer": "beautiful", "errorReason": "拼写错误", "masteryLevel": 50}'

# 6. 测试错题删除接口（替换QUESTION_ID为实际错题ID）
curl -X DELETE http://localhost:3000/api/error-questions/QUESTION_ID \
  -b "user_id=你的用户ID"
```
