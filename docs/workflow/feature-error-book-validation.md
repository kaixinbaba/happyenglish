## 0. 执行规则
1. 严格按步骤编号顺序执行，不跳步。
2. 每完成一步立刻勾选，不要一次做多步。
3. 阻塞时标记 `[~]` 并在备注写明阻塞点，继续下一步。
4. 发现 Bug 直接在备注写明问题，无需继续验收对应模块。
